# Data

Raw third-party datasets are intentionally not committed to this repository.

## Carbon Intensity API
Use the UK Carbon Intensity API:
https://api.carbonintensity.org.uk/

The Python ingestion script demonstrates how to retrieve daily intensity data.

## Extended analysis
For demand, generation mix and regional analysis, add a compatible UK electricity dataset and map it to the fields documented in `sql/analysis_queries.sql`.

Keep downloaded raw files local and place cleaned files in this directory only when their licence and redistribution terms permit it.
